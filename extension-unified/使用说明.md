# 贸大课程库 · 合一版

顶部“页面布局”可切换“多维表格”和“侧栏筛选”。切换保留当前搜索、筛选、排序、页码、课程范围和同步数据，并记住布局偏好。

- 多维表格：筛选框放在每列表头，紧凑显示。
- 侧栏筛选：左侧集中筛选，行内展示完整排课。
- 点击课程名可查看课程详情。

安装：解压压缩包，在 Chrome 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，加载 extension-unified 文件夹。此前两个扩展可自行停用，以免混淆。

从原站已登录的选课页面点击这个插件，再点“同步课程与主修”。新插件首次使用需重新同步；旧扩展缓存不会自动迁移。

离线文件“课程筛选合一版.html”可直接打开查看全校快照，个人主修需在插件中同步。

拖动表头右边缘调整列宽；侧栏布局下拖动侧栏右侧分隔线调整侧栏宽度。自动记住宽度。双击表头分隔线恢复该列默认宽度，“重置宽度”恢复全部宽度。键盘聚焦分隔线后可用左右方向键调整。
