## 贸大课程库 v0.3.1

将两种选课界面合为一个可切换布局的课程库：喜欢紧凑表格，或习惯左侧筛选，都可以用同一份数据。

### 主要功能

- 多维表格与侧栏筛选自由切换，保留筛选、排序和当前页。
- 拖动调整列宽及侧栏宽度，记住设置，支持一键重置。
- 按名称、课号、教师、学分、时间、地点、类型及余量查找课程。
- 登录原站后同步全校课程和自己的主修列表。
- 点击课程名称查看完整排课。

### 下载选择

- **uibe-course-filter-v0.3.1.zip**：解压后，在 Chrome 扩展管理页加载其中的 `extension-unified` 文件夹。在原站进入选课轮次后点击扩展图标，再同步课程与主修。
- **uibe-course-filter-offline-v0.3.1.html**：下载后双击即可浏览，不需要安装扩展；使用附带的全校快照，不能直接同步主修。
- **SHA256SUMS.txt**：附件校验值。

### 数据与验证

附带 2026-09-07 的全校课程快照（2,200 个教学班、948 门课程），不包含个人主修名单。人数和容量会变化，实际资格以原站为准。

13 项逻辑测试通过，完整浏览器端到端测试尚未完成。本版本只读取与筛选，不提交选课或退课。非学校官方项目。
