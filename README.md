# 贸大课程库

**让选课回到一张好用的表格。**

面向对外经济贸易大学选课系统的 Chrome 扩展：把全校课程放在一个页面中筛选、比较，并与当前账号的主修课程列表匹配。提供两种可随时切换的布局，支持拖动调整列宽和侧栏宽度。

> 非学校官方项目。当前版本只查询与筛选，不提交选课或退课。已选人数、容量和主修归属是同步时的快照，最终以原站为准。

## 下载与安装

从 [最新 Release](https://github.com/MochiaoChen/uibe-course-filter/releases/latest) 下载：

| 文件 | 用途 |
| --- | --- |
| `uibe-course-filter-v0.3.1.zip` | Chrome 扩展，可同步全校课程和个人主修列表 |
| `uibe-course-filter-offline-v0.3.1.html` | 双击即可打开的离线表格，使用随附全校课程快照 |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |

### Chrome 扩展

1. 下载并解压扩展 ZIP。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后的 **`extension-unified`** 文件夹。
4. 在 [学校选课系统](https://bkxk.uibe.edu.cn/) 登录并进入选课轮次。
5. 点击 Chrome 扩展菜单中的「贸大课程库」。
6. 点击「同步课程与主修」，保持原站标签页打开，等待完成。

同步完成后默认进入「我的主修」。首次同步前可以浏览随附的全校快照，此时主修标记为「尚未核验」。

### 更新扩展

用新版文件替换之前加载的文件夹内容，然后在 Chrome 扩展管理页点击该扩展的重新加载按钮，再重新打开课程库。若改为加载另一个文件夹，可能会被视为新的扩展，需要重新同步。

## 怎么用

### 两种布局，一份数据

在顶部「页面布局」中切换：

- **多维表格**：每列下方直接筛选，紧凑浏览课程。
- **侧栏筛选**：左侧集中填写条件，表格行内显示完整排课。

切换保留当前搜索、筛选、排序、页码和课程范围。布局偏好会保存在本机。

### 拖动调整宽度

- 拖动表头右边缘，调整对应列的宽度。
- 在侧栏布局中拖动侧栏右侧的分隔线，调整侧栏宽度。
- 双击列分隔线恢复该列默认宽度；「重置宽度」恢复全部默认宽度。
- 键盘聚焦分隔线后，可使用左右方向键调整。

### 筛选与比较

| 字段 | 支持的操作 |
| --- | --- |
| 课程名称 | 部分名称搜索 |
| 课程号 / 课序号 | 忽略大小写、空格，保留前导零 |
| 学分 | 下拉选择；按学分升序、降序排列 |
| 授课教师 | 姓名搜索 |
| 上课时间 | 输入 `12、13、51` 等原站代码，匹配任一、包含全部或排除 |
| 上课地点 | 文本搜索；`博学 207`、`博学楼207` 与 `博207` 等价 |
| 选课人数 / 容量 | 数值范围筛选，按人数、容量或剩余名额排序 |
| 课程类型 | 按原站类别筛选 |
| 主修归属 | 全部、我的主修、未在主修列表、待核验四种视图 |

不同字段的条件同时生效。点击课程名称可查看完整排课、开课单位、课程性质和本科计划容量。每页显示 40 个教学班。

时间代码沿用原站大节编码，不能把 `12` 简单理解成星期一第 2 小节。完整周次与实际节次请查看课程详情；排除时间时，不会把未知排课当作空闲时间。

## 「我的主修」如何判断

从当前登录页面读取名为「主修课程」的分类，按当前校区查询其完整列表，再分别匹配课程号和教学班 ID。

| 标记 | 含义 |
| --- | --- |
| 主修 · 已核验班次 | 具体教学班 ID 出现在主修列表中 |
| 主修课程 · 班次待核验 | 课程号匹配，但没有该具体教学班的对应证据 |
| 未在当前主修列表 | 完整同步的主修列表中没有匹配记录 |
| 主修尚未核验 | 尚未完成个人列表同步 |

**主修归属和课程类型是两个维度。** 体育、通识也可能出现在主修列表中。当前轮次的列表不等于完整培养方案，「未出现」不能解释为「不能计入毕业学分」。

## 数据与隐私

- 只访问 `https://bkxk.uibe.edu.cn/`，通过原站现有登录态读取课程列表。
- 扩展没有账号密码输入框，不导出登录 token、密码或 `secretVal`。
- 课程快照与布局设置保存在本机，没有项目自建服务器、统计脚本或遥测。
- 原站账号资料在页面内散列为缓存上下文标识，传回扩展的是散列标识，不是身份明文。轮次、校区也参与上下文核验。
- 同步校验分页总数、缺失编号与重复记录；全部完成后才更新缓存。
- 容量采用同一组 `numberOfSelected / classCapacity` 字段。本科计划容量单独显示，不代替当前可选容量。

随附数据是 **2026-09-07 15:00（北京时间）** 的 `2026-2027-1` 学期全校课程快照：**2,200 个教学班、948 门课程**。不含个人主修名单。容量和人数会变化，使用前请同步。

## 开发

不需要安装前端依赖。使用现代 Node.js 和 Python 3：

```sh
npm test
npm run build
```

构建产生一个自包含 HTML 和一个扩展 ZIP。Chrome 扩展直接加载 `extension-unified/` 即可。

```text
extension-unified/      当前发布的合一版扩展
  app.js               界面、布局切换、拖动宽度与同步流程
  core.js              筛选、归属匹配、排序和分页校验
  reader.js            原站页面内的只读数据适配
  background.js        扩展页与原站标签页之间的消息桥接
  snapshot.json        已筛除登录与个人身份字段的全校快照
scripts/build-unified.py
                       构建离线 HTML 和扩展包
tests/unified-*.test.js 自动测试
docs/                  发布记录
```

## 验证范围与已知限制

- 自动测试覆盖真实快照、组合筛选、编号规范化、主修证据区分、空值与容量、分页完整性、账号变化和登录失效。
- 原站已核实主修分类 `FANKC`、分页参数和 `tcList` 教学班结构。
- 拖动交互和完整扩展同步尚未完成自动化浏览器端到端测试。测试通过不代表所有选课轮次都适配。
- 依赖原站页面的 Vue 对象与 axios 实例；原站升级可能需要更新适配器。
- 不支持自动选课、退课、抢课、资格绕过或毕业学分核算。
